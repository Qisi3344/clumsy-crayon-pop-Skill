# clumsy-crayon-pop

笨拙蜡笔 × 波普配色。用 Python 一笔一笔撒出来的蜡笔画，不是滤镜，不是生图。

- `SKILL.md` —— skill 说明：5 组波普配色、波普画法、引擎函数速查
- `palettes/palettes.json` —— 5 组配色的机器可读版
- `themes.md` —— 6 个推荐主题
- `crayon/crayon_lib.py` —— 蜡笔渲染引擎
- `examples/` —— 范例脚本和出图

依赖：`pip install pillow numpy`。
